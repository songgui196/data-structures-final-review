## 差异与纠错记录

### 选择题分值

- 纪要正文“考试题型与分值说明”和内嵌饼图均写40分。
- 第一张AI概览图写20分；按该图列出的五项相加仅80分，与总分100分不一致。
- 处理：以40分作为当前工作值，同时保留待核实标记。此为依据材料内部一致性作出的选择，不能声称已获教师再次确认。

### 循环队列判空与判满

- 纪要“智能章节”04:09处把尾指针取模和判空混在一句话里，表述不够准确。
- 教材3.5.2在“预留一个空位”的约定下明确：队空为 `Q.front == Q.rear`；队满为 `(Q.rear + 1) % MAXQSIZE == Q.front`；数组容量为m时最多容纳m−1个元素。
- 处理：网页知识点采用教材公式，并明确适用约定；不把一种存储方案的条件套用到所有队列实现。

### 顺序栈的指针名称

- 纪要用“头尾指针指向同一地址”描述栈空，容易与队列混淆。
- 教材3.3.2（印刷第66页、PDF第78页）明确使用栈底指针base与栈顶指针top，空栈条件为 `S.top == S.base`；非空时top指向栈顶元素的下一个位置。
- 处理：按教材顺序栈的定义展示，不推广为所有栈实现的通用判空条件。

### 概率性描述与条件句

- BF/KMP：纪要收录了“绝对会考一个，甚至两个都会考”的引述，属于明确强调项，但来源仍是智能纪要。
- 图综合题：原引述是“如果是出现在综合应用里的话”，存在条件；“综合题必定考图”超出了原材料能支持的结论。
- 广义表：总结段写“仅会出现在选择题”，智能章节写“大概率仅出现在选择题”。处理为“选择题优先，是否仅限选择题待核实”。
- 处理：分别记录“纪要明确说明”“纪要收录强调”“纪要推测”“建设建议”，不把推测升级为确定考题。

## 对复习知识库与skill的调整

### 内容组织

采用“章节浏览”和“五类题型训练”两个入口，链接同一份知识点。每个知识点包含：教材定义与约定、步骤或公式、一道重构例题、易错点、相关算法、教材出处、考试范围依据。

考试分值用于组织入口和检查训练覆盖，不直接等比例分配学习时间。各章课后选择题占独立入口；不承诺仅做某批题即可拿满分。

### 代码训练

程序填空优先忠实于教材算法版本，保留变量名、下标起点和接口约定。教材类C与标准C分别标记；标准C转换版不能冒充原教材源码。未核对原页的代码、答案保留待核验状态。

KMP的next、nextval必须说明所用下标及回退约定。图遍历、最小生成树、哈夫曼树等若存在并列选择，题目需给出取舍规则，或答案接受符合规则的等价结果。建树题需交代输入表示、空结点标记或足以确定结构的遍历信息。

### 第一批样本建议

将第一批内容重点调整到“串的模式匹配”：BF、KMP、next、nextval及对应代码填空，以回应纪要的明确强调。范围保持在单个模块，连同概念、手算、代码、自测和出处一起验证。随后建设二叉树与哈夫曼、图综合题、折半查找、排序专项；基础选择题逐章并行补齐。

该顺序是建设建议，不是各章分值预测。栈和队列的已核验公式可以作为校验示例继续使用。
