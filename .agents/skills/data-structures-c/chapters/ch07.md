## 顺序、折半与分块查找

**复习层级：** focus；**依据：** explicit。

顺序查找逐项比较，适用于无序表，最坏O(n)。折半查找要求表有序且支持随机访问；在闭区间[low,high]内比较mid。若A[mid]<key，则low=mid+1；若更大，high=mid−1；若相等则命中。每轮区间约缩小一半，时间O(log n)。分块查找块间索引有序、块内再顺序查找，折中动态更新与搜索速度。重复值题须规定返回任一匹配位置还是左右边界；代码要防溢出式中点计算与越界。

**核心概念**

- **折半前提：**关键字有序且可随机访问。
- **闭区间更新：**目标较大时low=mid+1；较小时high=mid−1。
- **分块查找：**先查索引确定块，再在块内顺序查找。

**操作步骤**

1. 初始化闭区间[0,n−1]。
2. 计算中点并比较。
3. 保留包含目标的半区且排除已比较中点。
4. 区间空时报告失败。

**公式与适用条件**

| 项目 | 公式或结论 | 适用条件 |
|---|---|---|
| 折半查找 | O(log n) | 有序随机访问表 |
| 顺序查找最坏 | O(n) | 任意线性表 |

**易错点**

- 未排序表不满足折半查找前提。
- 链表按序但无法高效随机访问中点。
- mid命中重复值时不一定是第一个出现的位置。

### 例题：闭区间折半查找

**题目：**在[3,8,12,17,25,31,42]中查找17，使用0起始下标。

1. low=0,high=6。
2. mid=3，A[3]=17。

**结论：**比较一次，在下标3命中。

**教材来源：**7.2.1–7.2.3 顺序、折半与分块查找；印刷页231–237（PDF第243–249页）。

**范围依据：**考试纪要明确强调折半查找填空与实现；顺序、分块查找保留比较背景。

### 重构类C示例：0-based 闭区间折半查找

```c
int BinarySearch(int A[], int n, int key) {
    int low = 0, high = n - 1;
    while (low <= high) {
        int mid = low + (high - low) / 2;
        if (A[mid] == key) return mid;
        if (A[mid] < key) low = mid + 1;
        else high = mid - 1;
    }
    return -1;
}
```

- A为升序数组，n为元素数，返回一个匹配下标或-1。
- 中点使用low+(high-low)/2降低加法溢出风险。

## 二叉排序树查找与构造

**复习层级：** focus；**依据：** emphasis。

二叉排序树满足左子树关键字小于根，右子树关键字大于根，且左右子树也满足该性质。查找按比较方向逐层下降；插入新关键字时走同一路径至空链接并建立新叶。中序遍历得到递增序列。树的形状受插入顺序影响，接近平衡时查找O(log n)，单支树最坏O(n)。若有重复值，需预先定义计数或放置方向；本库建树题使用互异关键字。构造过程应逐个展示比较路径，而非只画最终树。

**核心概念**

- **BST序：**左子树<根<右子树。
- **构造：**依输入次序逐个比较至空孩子链接并插入。
- **中序性质：**互异键BST的中序遍历为严格递增序列。

**操作步骤**

1. 首个关键字建立根。
2. 逐个与当前结点比较。
3. 较小向左、较大向右直到空链接。
4. 按中序核验全局顺序。

**公式与适用条件**

| 项目 | 公式或结论 | 适用条件 |
|---|---|---|
| 平衡时查找 | O(log n) | 树高对数级 |
| 最坏查找 | O(n) | 单支退化树 |

**易错点**

- 不能只检查直接孩子，要满足左右子树全局范围。
- 递增插入可形成向右单支树。
- 重复关键字的归属必须有约定。

### 例题：按序列建BST

**题目：**按8、3、10、1、6插入，求树结构和中序序列。

1. 8为根。
2. 3左、10右。
3. 1沿8左、再沿3左；6沿8左、再沿3右。

**结论：**根8，左子3（孩子1、6），右子10；中序1、3、6、8、10。

**教材来源：**7.3.1 二叉排序树；印刷页237–241（PDF第249–253页）。

**范围依据：**纪要提到按输入序列构造二叉排序树；重复关键字须由题目另行规定。

### 重构类C示例：BST查找

```c
while (p != NULL && p->key != key) {
    if (key < p->key) p = p->lchild;
    else p = p->rchild;
}
return p;
```

- 假定互异关键字并按左小右大定义。
- p为空表示查找失败；非空表示命中。

## 散列表与冲突处理

**复习层级：** foundation；**依据：** suggestion。

散列函数将关键字映射到有限表地址，不同关键字可能映射到同一位置，称为冲突。开放定址在表内探测后继位置；链地址法在一个地址维护冲突链。线性探测从初始地址依次检查并按表长循环。装填因子α=n/m表示记录数与表长比，开放定址中装填越高，冲突通常越多。查找遇空槽判失败的前提是插入和删除正确维护空、占用、删除标记状态。作表时应同时写初始散列地址与探测后最终落点。

**核心概念**

- **冲突：**两个不同关键字计算到相同地址。
- **线性探测：**冲突后依序检查下一个槽位并循环回表头。
- **装填因子：**α=n/m。

**操作步骤**

1. 逐个计算H(key)。
2. 若已占用，按指定探测策略继续。
3. 记录最终落点并更新占用状态。

**公式与适用条件**

| 项目 | 公式或结论 | 适用条件 |
|---|---|---|
| 装填因子 | α=n/m | n个记录、表长m |

**易错点**

- 把冲突与关键字相同混为一谈。
- 线性探测需按表长循环取余。
- 删除不能简单清空槽位而破坏后续探测链。

### 例题：线性探测

**题目：**表长11，H(k)=k mod 11，插入22、33、44。

1. 三个关键字初始地址均为0。
2. 22放0，33探测放1，44再探测放2。

**结论：**最终下标依次为0、1、2。

**教材来源：**7.4 散列查找；印刷页269–276（PDF第281–288页）。

**范围依据：**散列查找作为章节必要背景与选择题训练，不承诺题型或分值。

## 平衡树与多路查找概览

**复习层级：** overview；**依据：** suggestion。

平衡二叉树在二叉排序树基础上限制子树高度差，并通过旋转保持对数高度；红黑树用颜色约束实现较宽松平衡。B树每个结点可含多个关键字和多棵子树，适合外存多路索引、降低磁盘访问次数。不同查找结构通过额外的存储或维护代价换取较稳定的查找路径。答辨析题时分清每种结构的组织方式与适用场景，不将二叉排序树平均性能和最坏性能混为一谈。

**核心概念**

- **平衡二叉树：**通过旋转限制左右子树高度差。
- **B树：**结点含多个关键字和多路子树的平衡查找树。

**操作步骤**

1. 确定查找结构与存储层次。
2. 说明该结构维护的平衡或排序性质。
3. 据树高或磁盘访问分析性能。

**易错点**

- 普通BST不自动保证平衡。
- B树结点的多路结构与二叉树不同。
- 性能结论需注明最好、平均或最坏情形。

### 例题：选择查找结构

**题目：**数据存于外存且每次磁盘I/O代价高，需减少访问层数，可优先考虑何种树型索引？

1. 目标是减少外存访问层数。
2. 采用较高分支度的平衡多路查找树。

**结论：**可考虑B树类多路索引。

**教材来源：**7.3.2 平衡二叉树；7.3.3 红黑树；7.3.4 B-树；印刷页244–267（PDF第256–279页）。

**范围依据：**平衡树、B树作为知识背景和客观题复习，不声称未点名内容不考。

        if (A[mid] < key) low = mid + 1;
        else high = mid - 1;
    }
    return -1;
}
