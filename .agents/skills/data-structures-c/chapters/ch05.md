## 树的基本术语与性质

**复习层级：** foundation；**依据：** emphasis。

树是n个结点的有限集合，非空时有且仅有一个根，其余结点划分为互不相交的子树。结点的度是孩子数，树的度是各结点度的最大值；叶结点度为0。层次从根的第一层开始，树的深度是最大层次。树中除根外每个结点有一个双亲，所以边数为n−1。非空二叉树还满足叶结点数n0等于度为2的结点数n2加1。答题时先确认一般树或二叉树，再使用对应性质；满二叉树、完全二叉树、平衡二叉树不可混为一谈。

**核心概念**

- **结点的度：**该结点所含孩子的个数；叶结点的度为0。
- **树的深度：**所有结点最大层次；按本书约定根结点位于第一层。
- **二叉树叶数关系：**在非空二叉树中，若度为0、1、2的结点数分别为n0、n1、n2，则n0=n2+1。

**操作步骤**

1. 标出根并核对每个非根结点是否仅有一个双亲。
2. 需要求边数时用非根结点数n−1。
3. 二叉树计数时分别统计度为0、1、2的结点。

**公式与适用条件**

| 项目 | 公式或结论 | 适用条件 |
|---|---|---|
| 边数 | n−1 | 非空树 |
| 二叉树叶结点关系 | n0=n2+1 | 非空二叉树 |

**易错点**

- 把树的度与根的度相混；树的度是全树最大结点度。
- 把根算作第0层与教材的第1层约定混用。
- 将“完全”误认为每个结点都必须有两个孩子。

### 例题：由内部结点数求二叉树结点数

**题目：**一棵二叉树中有8个度为2的结点、5个度为1的结点，求叶结点数与总结点数。

1. 用n0=n2+1得到n0=9。
2. 相加n0+n1+n2=9+5+8=22。

**结论：**叶结点9个，总结点22个。

**教材来源：**5.1 树和二叉树的定义；5.4.1 二叉树的性质；印刷页137–146（PDF第149–158页）。

**范围依据：**纪要强调二叉树与树的基础辨析；一般树的计数性质用于背景训练，不提升为确定题型。

## 二叉树遍历与建树

**复习层级：** focus；**依据：** explicit。

前序是根—左—右，中序是左—根—右，后序是左—右—根，层序使用队列按层访问。前三种深度遍历递归调用完全相同，区别仅在访问根的位置。结点值互异时，前序加中序或后序加中序可唯一确定二叉树；仅给前序和后序通常无法判断单孩子在左还是右。重建时先在中序区间定位根，再按左子树结点数切分另一个序列。题目须交代遍历序列和结点互异等条件；实现固定闭区间，空区间返回空树。

**核心概念**

- **前序：**访问根、递归左子树、递归右子树。
- **中序：**递归左子树、访问根、递归右子树。
- **后序：**递归左子树、递归右子树、访问根。
- **唯一恢复条件：**结点互异时，前序/后序与中序配合可以唯一重建。

**操作步骤**

1. 先识别已知序列中的根结点。
2. 在中序序列里找到根，划分左右子树。
3. 按左右子树长度划分其他遍历序列。
4. 递归处理左右区间，遇空区间返回。

**易错点**

- 只用前序和后序不能总是唯一恢复有单孩子的树。
- 结点值重复会使中序中根位置不唯一。
- 层序遍历用队列，不能照搬深度递归次序。

### 例题：前序和中序重建

**题目：**前序A,B,D,E,C，中序D,B,E,A,C。求后序与层序。

1. 前序首项A为根，中序以A划出左D,B,E和右C。
2. 左子树根B，D、E分别是其左右孩子。
3. 后序按左、右、根；层序按队列逐层访问。

**结论：**后序D,E,B,C,A；层序A,B,C,D,E。

**教材来源：**5.4.2 二叉树的存储结构；5.5.1 遍历二叉树；印刷页146–153（PDF第158–165页）。

**范围依据：**考试纪要明确点名遍历和依遍历序列建树；本库训练均提供足以唯一确定结构的输入。

### 重构类C示例：先序递归

```c

    if (T == NULL) return;
    Visit(T->data);
    PreOrder(T->lchild);
    PreOrder(T->rchild);

```

## 哈夫曼树、编码与WPL

**复习层级：** focus；**依据：** explicit。

哈夫曼树通过反复合并当前森林中权值最小的两棵树构造；新树权值为两者之和，再放回候选集合。n个非零权叶结点最终形成n−1个内部结点。约定左分支编码0、右分支编码1时，每个叶的根到叶路径组成字符码，任一码都不是另一码的前缀。带权路径长度WPL等于叶权值乘其深度后求和；交换左右孩子不改变WPL。手算须每轮从整个候选森林重新挑两棵最小树；并列最小值可能给出不同树形，但总权长度仍可最优。

**核心概念**

- **哈夫曼合并：**每次取候选中两棵最小权值树合并，所得权值加入候选。
- **前缀码：**字符编码对应叶路径，因此字符码之间没有前缀关系。
- **带权路径长度：**叶权值乘以叶深度后求和。

**操作步骤**

1. 把所有叶权作为候选森林。
2. 每轮选两个最小者合并并记录新权值。
3. 直到剩余一棵树。
4. 按约定左右分支编码，计算每个叶的深度和WPL。

**公式与适用条件**

| 项目 | 公式或结论 | 适用条件 |
|---|---|---|
| 哈夫曼树内部结点 | n−1 | n个非零权叶 |
| WPL | Σ wi×li | wi为叶权，li为根到叶边数 |

**易错点**

- 每轮需要将新合并的权值重新加入候选集合。
- 深度按边数而非结点数计；根深度为0。
- 并列最小值可能产生不同树，不得将一种任意左右次序说成唯一。

### 例题：合并四个字符权值

**题目：**A:2、B:3、C:7、D:9，求一个哈夫曼WPL。

1. 先合并最小叶权 2 与 3，得到权 5。
2. 再合并 5 与 7 得到 12，最后合并 9 与 12 得到根权 21。
3. 叶 A、B、C、D 到根的边数依次为 3、3、2、1。
4. WPL 等于叶权乘路径长度之和，也等于三次合并所得的权值之和 5+12+21=38。

**结论：**WPL=38，即 2×3+3×3+7×2+9×1。

**教材来源：**5.7 哈夫曼树及其应用；印刷页162–168（PDF第174–180页）。

**范围依据：**纪要明确强调哈夫曼相关综合题；权值并列时按题设规则，或接受同样最优的树。

### 重构类C示例：按叶深计算WPL

```c
int WPL(Leaf leaves[], int n) {
    int total = 0;
    for (int i = 0; i < n; ++i)
        total += leaves[i].weight * leaves[i].depth;
    return total;
}
```

- 示例假设叶记录已经包含权值和以边计的深度。
- Leaf类型与数组容量需在具体程序中定义；未在此独立编译。

## 树与二叉树的存储表示

**复习层级：** overview；**依据：** suggestion。

二叉链表结点保存数据、左右孩子指针；空孩子用空指针表示。顺序存储适合完全二叉树，但稀疏树会浪费较多数组单元；数组孩子下标关系须明确采用0还是1起始。孩子兄弟表示可用“第一个孩子”和“下一个兄弟”两个指针表示一般树。线索二叉树利用空指针记录遍历前驱或后继，需以标志域区分线索与孩子链接。选择存储结构时结合树的稠密度和基本操作需求；题目若未给空标记和根下标，不能自行假定序列化格式。

**核心概念**

- **二叉链表：**每个二叉树结点含数据、左孩子和右孩子域。
- **孩子兄弟表示：**一般树以首孩子、右兄弟两个关系表示。
- **线索：**用空孩子指针保存指定遍历次序的前驱或后继。

**操作步骤**

1. 确认需表示一般树还是二叉树。
2. 若需频繁定位孩子，按结点关系选择链接表示。
3. 使用线索时读取标志域并遵循对应遍历次序。

**易错点**

- 完全二叉树的数组关系不宜不加检查地套到稀疏树。
- 线索指针与普通孩子指针必须由标志域区分。

### 例题：选取稀疏树表示

**题目：**有一棵高度较大且结点稀疏的二叉树，要支持左右孩子访问，选顺序存储还是二叉链表？

1. 确认结构稀疏。
2. 顺序数组可能保留大量空位置。
3. 二叉链表为实际结点保存左右孩子链接。

**结论：**通常选择二叉链表；若应用需要随机按完全树编号访问，则再评估数组表示。

**教材来源：**5.4.2 二叉树的存储结构；5.5.2 线索二叉树；5.6.1 树的存储结构；印刷页146–160（PDF第158–172页）。

**范围依据：**存储表示、线索与树森林转换用于章节完整性和选择题备查，不据此声称未涉及内容不考。

### ch05-q11 · 编程

**参考答案**  累计所有叶子的weight×depth。

2. 遍历叶并累加weight*depth。

