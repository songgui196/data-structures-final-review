## BF：逐起点比较与失配回退

**复习层级：** focus；**依据：** emphasis。

BF 从指定起点逐一尝试主串的候选子串。每一趟都将模式第一个字符对准一个新起点，逐字符比较；失败时既回退主串指针，也重置模式指针。适合短串、一次性查找或用作其他匹配算法的正确性参照。以下仅处理非空模式与合法起点，返回首次匹配的1-based位置，失败返回0。

**核心概念**

- **主串与模式：**主串 S 是被检索的字符序列，模式 T 是要查找的连续子串。匹配要求字符次序相同且连续，不是从主串任意抽取若干字符。
- **比较指针与候选起点：**i 指向主串当前字符，j 指向模式当前字符；一趟比较中，候选起点始终等于 i-j+1，不能把正在比较的位置 i 当成匹配起点。
- **回退的依据：**失配后下一候选起点是原起点加1，因此用失配时的旧 i、旧 j 计算 i=i-j+2，再令 j=1；两条赋值的先后顺序有意义。
- **代价与适用条件：**成功时不必扫描主串剩余部分；最坏情况下很多候选都比较到模式末尾才失败，时间上界 O(nm)，辅助空间 O(1)，不需要预处理。

**操作步骤**

1. 先确认字符存于 ch[1..length]，T 非空且 1≤pos≤S.length，初始化 i=pos、j=1。
2. 只在 i≤n 且 j≤m 时比较：相等则 i、j 同增，否则按旧 j 回退主串并将 j 置1。
3. 循环结束先检验 j>m；若成立返回 i-m，否则返回0。成功位置是模式首字符对应位置。

**公式与适用条件**

| 项目 | 公式或结论 | 适用条件 |
|---|---|---|
| 失配回退 | i ← i-j+2；j ← 1 | 两式顺序执行；i、j 均为失配时的1-based比较指针 |
| 成功返回 | position=i-m | m=T.length，且循环结束时 j>m |
| 最坏代价 | O(nm) 时间，O(1) 额外空间 | n 为主串长，m 为模式长；比较大量重叠候选时 |

**易错点**

- 不能先执行 j=1 再计算 i-j+2，否则丢失本趟起点。
- 不是每次失配都将 i 加1；i 是比较位置，并非本趟起点。
- 本接口未定义空模式的查找语义，不能照搬其他库返回值。

### 例题：按趟记录 BF 的比较次数

**题目：**S="ababcabcacbab"，T="abcac"，pos=1；求首次出现位置与字符比较次数。

1. 起点1：a=a、b=b、a≠c，比较3次。
2. 起点2：b≠a，比较1次。起点3：a=a、b=b、c=c、a=a、b≠c，比较5次。
3. 起点4、5分别在首字符失配，各1次；起点6连续5次相等。
4. 合计3+1+5+1+1+5=16次；成功后 i=11、j=6，返回11-5=6。

**结论：**首次匹配位置6，共16次字符比较。

**教材来源：**4.3.3 串的模式匹配算法：算法4.1；印刷页110–111（PDF第122–123页）。

**范围依据：**范围依据收录了 BF/KMP 的强烈强调，但不是正式命题保证。

### 重构类C示例：BF 核心函数

```c
#define MAXLEN 1000
typedef struct { char ch[MAXLEN + 1]; int length; } SString;
int Index_BF(SString S, SString T, int pos) {
    int i = pos, j = 1;
    /* Preconditions: 1 <= pos <= S.length, 1 <= T.length <= MAXLEN. */
    while (i <= S.length && j <= T.length) {
        if (S.ch[i] == T.ch[j]) { ++i; ++j; }
        else { i = i - j + 2; j = 1; }
    }
    return j > T.length ? i - T.length : 0;
}
```

- 按教材算法4.1重构，补全变量声明并将排版运算符转成C形式；不是教材源码逐字转写。
- ch[0]不用；调用者保证S、T的length与已存字符一致，长度不超过MAXLEN。
- 未执行C编译；例题用独立比较过程复核。

## KMP：主串不回退的匹配过程

**复习层级：** focus；**依据：** emphasis。

KMP 利用模式中已经确认相等的前后缀，在失配时移动模式的对齐位置，主串比较指针 i 不减小。它并非保证每个主串字符只比较一次，而是避免重新从主串更早位置开始匹配。适合模式存在较多重复部分、主串较长或需要单向读取的情况；同一模式可复用其辅助表。

**核心概念**

- **失配转移：**当前 S.ch[i]≠T.ch[j] 时保持 i 不变，令 j=next[j]，将模式中一个可能继续匹配的位置移到当前主串字符处。辅助表只由 T 决定。
- **j=0 的哨兵含义：**当第一个模式字符也不能匹配时，next[1]=0。j=0 只是控制状态，不表示读取T.ch[0]；下一轮直接执行 ++i、++j。
- **已匹配部分：**在 j>0 的比较状态，T[1..j-1] 与当前候选的主串片段相等；回退保留可确认相等的后缀，避免重新比较这部分。
- **时间与接口：**next 构造 O(m)，匹配 O(n)，合计 O(n+m)，辅助表 O(m)。此处 T 非空、1≤pos≤n，成功仍返回1-based首位置，失败返回0。

**操作步骤**

1. 根据明确的1-based约定先求 next，初始化 i=pos、j=1。
2. j=0 时只移动两个指针，不做字符比较；否则字符相等则同增，失配则仅令 j=next[j]。
3. 按 j>m 判断成功并返回 i-m；记录比较次数时只统计实际的字符相等性判断。

**公式与适用条件**

| 项目 | 公式或结论 | 适用条件 |
|---|---|---|
| 失配时 | (i,j) → (i,next[j]) | j>0且S.ch[i]≠T.ch[j]；next[1]=0 |
| 总复杂度 | O(n+m) 时间，O(m) 辅助空间 | 包括模式预处理；只计匹配阶段为 O(n) |

**易错点**

- 主串指针不回退不等于主串每个字符只比较一次；同一 i 可能对应多个 j。
- 必须先判断 j==0，利用短路求值避免访问 T.ch[0]。
- 不能把以-1为哨兵的0-based表直接传入本版本。

### 例题：用同一数据对比 BF 与 KMP

**题目：**S="ababcabcacbab"，T="abcac"，pos=1；采用普通 next 表计算匹配过程。

1. T 的 next[1..5]=[0,1,1,1,2]。先比较(1,1)、(2,2)，在(3,3)失配，j回退到1而i仍为3。
2. 随后(3,1)、(4,2)、(5,3)、(6,4)相等，(7,5)失配；next[5]=2，转为(7,2)。
3. (7,2)、(8,3)、(9,4)、(10,5)相等，结束时 i=11、j=6。
4. 字符比较共12次，返回11-5=6；与BF的16次比较结果一致。

**结论：**首次匹配位置6；普通next版KMP共12次字符比较。

**教材来源：**4.3.3 串的模式匹配算法：算法4.2；印刷页112–116（PDF第124–128页）。

**范围依据：**范围依据明确强调 BF/KMP；题型安排属于自编训练。

### 重构类C示例：KMP 核心函数

```c
/* SString uses ch[1..length], as in the BF example. */
int Index_KMP(SString S, SString T, int pos, const int next[]) {
    int i = pos, j = 1;
    while (i <= S.length && j <= T.length) {
        if (j == 0 || S.ch[i] == T.ch[j]) { ++i; ++j; }
```

## next：失配位置前缀的最长相等真前后缀

**复习层级：** focus；**依据：** explicit。

本章 next[j] 表示在模式第 j 个字符失配后，下一次应比较的模式位置，不是前后缀的长度本身。采用教材1-based约定 next[1]=0；j≥2时查看的是 T[1..j-1]，求其最长相等真前缀与真后缀长度，再加1。若没有非空相等真前后缀，则长度记0，所以 next[j]=1。

**核心概念**

- **真前缀和真后缀：**真前缀不含整个被考察串，真后缀也不含整个被考察串；比较对象是失配前已经匹配的片段，不能包含尚未匹配的T[j]。
- **回退位置与长度：**若最长相等真前后缀长度为l，已有l个字符无需重比，下一比较位置为l+1；j=1单独定义为0，代表首字符失配的哨兵状态。
- **递推候选：**求next时，i指向模式的当前字符，j表示当前候选前缀位置；字符不等时用 j=next[j] 缩短候选，不能简单只减1。
- **使用范围：**仅由模式本身决定，可供多个主串复用；构造耗时O(m)、表空间O(m)。本节只存next[1..m]，不额外计算整串匹配后的next[m+1]。

**操作步骤**

1. 手算时列 j、T[j]、T[1..j-1]、最长真边界长度l；第1项写0，其余写l+1。
2. 线性算法从 i=1、j=0 开始；若 j=0 或 T[i]=T[j]，先同增 i、j，再令next[i]=j。
3. 否则令 j=next[j] 并保留 i；循环条件 i<m，避免生成本接口不需要的 m+1 项。

**公式与适用条件**

| 项目 | 公式或结论 | 适用条件 |
|---|---|---|
| 教材 next 定义 | next[1]=0；next[j]=1+L(T[1..j-1])，2≤j≤m | L 为最长相等真前后缀长度，空边界长度为0 |
| 递推成功 | next[i+1]=j+1 | 当前候选为j=next[i]，且j=0或T[i]=T[j] |

**易错点**

- 不要对T[1..j]求边界；这会把表整体错位。
- “无非空相等前后缀”时填1，只有首项固定0。
- 重复字符可产生较长边界；取最长，不是任选一个相等前后缀。

### 例题：独立计算一个非教材模式的 next

**题目：**求模式 T="ababaa" 的 next[1..6]，明确字符从1开始编号。

1. j=1：哨兵0。j=2：此前为a，真边界长度0，故next[2]=1。
2. j=3：此前为ab，最长真边界长度0，故next[3]=1。j=4：此前为aba，边界a长1，故为2。
3. j=5：此前为abab，边界ab长2，故为3。j=6：此前为ababa，最长边界aba长3，故为4。
4. 用递推算法另算一次得到同表；最后的a属于失配位置，求next[6]时不纳入前缀。

**结论：**next[1..6]=[0,1,1,2,3,4]。

**教材来源：**4.3.3：式(4-1)、算法4.3；印刷页114–117（PDF第126–129页）。

**范围依据：**范围依据直接列出 next 与 nextval；不据此限定正式考试题型。

### 重构类C示例：1-based next 构造

```c
void get_next(SString T, int next[]) {
    int i = 1, j = 0;
    next[1] = 0;
    while (i < T.length) {
        if (j == 0 || T.ch[i] == T.ch[j]) {
            ++i; ++j; next[i] = j;
        } else j = next[j];
    }
}
```

- 前置条件：1≤T.length≤MAXLEN，next至少有T.length+1个整型单元，0号不用。

## nextval：跳过必然再次失配的候选

**复习层级：** focus；**依据：** explicit。

nextval 在普通 next 的基础上压缩一段必然失败的回退链。已经知道 S[i]≠T[j]，如果回退候选 k=next[j] 满足 T[k]=T[j]，再拿 S[i] 与 T[k] 比较一定失败，可以继续跳转。它改变的是辅助表中的回退目标，KMP匹配的主循环和首次匹配结果均不改变。

**核心概念**

- **修正规则：**nextval[1]=0；对j≥2，令k=next[j]。若T[j]≠T[k]则保留k，否则取nextval[k]；因为k<j，可由前向后的已算值递推。
- **重复字符作用：**重复字符越多，失配后越可能重复遇到同一字符，修正表可跳过这些候选。它不是将所有next项减1，也不是与主串内容一起预处理。
- **零值的含义：**修正表除了第1项外也可能为0，表示可直接跳到哨兵；此时匹配循环按j=0分支移动i、j，不应访问模式的0号单元。
- **复杂度与边界：**构造仍为O(m)，辅助空间O(m)，整体匹配仍是O(n+m)量级；具体比较次数可能减少，但不能声称任意输入都严格更快。表和主循环必须沿用同一1-based约定。

**操作步骤**

1. 先算普通next，以方便用定义核对；再按j从2到m依次比较T[j]与T[next[j]]。
2. 字符不同保留next[j]；相同则取已求出的nextval[next[j]]，必要时效果等同于跳过整条重复字符链。
3. 用重复字符模式在相同主串上分别运行两种辅助表，核对匹配位置相同并只统计字符比较。

**公式与适用条件**

| 项目 | 公式或结论 | 适用条件 |
|---|---|---|
| 教材修正 | nextval[1]=0；若T[j]=T[next[j]]则nextval[j]=nextval[next[j]]，否则nextval[j]=next[j] | 2≤j≤m；先有普通next或使用等价线性递推 |

**易错点**

- 不要把nextval[5]理解成T[1..5]的最长边界长度。
- 有重复字符也不能把整张表一律置0，应逐项判断回退目标字符。
- nextval省去的是已能证明失败的字符比较，不是跳过可能的合法匹配。

### 例题：比较普通表与修正表

**题目：**S="aaabaaaab"，T="aaaab"。求 next、nextval，以及两种KMP的字符比较次数。

1. 普通next逐项为[0,1,2,3,4]；T[2]、T[3]、T[4]均为a，与各自候选字符相同，依次跳到0。
2. T[5]=b，而T[next[5]]=T[4]=a，不同，故nextval[5]=4；修正表为[0,0,0,0,4]。
3. 前三个a匹配后在(i,j)=(4,4)处b≠a。普通表继续比较(4,3)、(4,2)、(4,1)，修正表直接令j=0。
4. 两者均从S[5]开始成功匹配5字符，普通表比较3+4+5=12次，修正表比较3+1+5=9次。

**结论：**next=[0,1,2,3,4]，nextval=[0,0,0,0,4]；首次位置均为5，比较次数分别12、9。

**教材来源：**4.3.3：算法4.4及图4.13；印刷页117–118（PDF第129–130页）。

**范围依据：**范围依据直接列出 nextval，训练需区分它与普通 next。

### 重构类C示例：1-based nextval 构造

```c
void get_nextval(SString T, int nextval[]) {
    int i = 1, j = 0;
    nextval[1] = 0;
    while (i < T.length) {
        if (j == 0 || T.ch[i] == T.ch[j]) {
            ++i; ++j;
            if (T.ch[i] != T.ch[j]) nextval[i] = j;
            else nextval[i] = nextval[j];
        } else j = nextval[j];
    }
}
```

- 按教材算法4.4重构，补变量声明并规范符号；不是逐字教材源码。
- T非空、字符下标1..m，输出数组容量至少m+1；while使用i<m。
- 此函数内部回退使用nextval[j]；比较时仍靠j==0短路保护。代码未作C编译验证。

## 二维数组：行优先、列优先与非零下界地址

**复习层级：** focus；**依据：** explicit。

二维数组顺序存储需要把二维下标映射成一维偏移。按行优先先存完一整行再存下一行；按列优先先存完一整列再存下一列。公式适用于每个元素等长、连续、未压缩的存储；须先说明基址对应哪个元素，以及每个元素占多少个地址单位。

**核心概念**

- **维长与下界：**若A[l1..u1,l2..u2]，则行数r=u1-l1+1、列数c=u2-l2+1；实际下标必须先减各自下界，不能把下标值直接当成行列偏移。
- **行优先：**目标之前有i-l1个完整行，每行c个元素，再加本行j-l2个元素，故元素偏移为(i-l1)c+(j-l2)。教材式(4-13)给出0下界情形。
- **列优先：**目标之前有j-l2个完整列，每列r个元素，再加本列i-l1个元素，故元素偏移为(j-l2)r+(i-l1)；这是由教材列序说明直接展开。
- **适用边界：**基址B取LOC(A[l1,l2])，元素宽度w与B使用同一地址单位；本节字节编址则w以字节计。普通C二维数组按行存储；公式不能直接套在压缩矩阵或指针行数组上。

**操作步骤**

1. 写出合法下标范围并求r、c，明确B对应左上角元素而非任意已知元素。
2. 按存储顺序先数完整行或完整列，再加所在行或列内的剩余元素数。
3. 用元素偏移乘w后加B；用首元素偏移0、末元素偏移rc-1检查公式。

**公式与适用条件**

| 项目 | 公式或结论 | 适用条件 |
|---|---|---|
| 行优先 | LOC(A[i,j])=B+((i-l1)c+(j-l2))w | B=LOC(A[l1,l2])；l1≤i≤u1，l2≤j≤u2；连续等长存储 |
| 列优先 | LOC(A[i,j])=B+((j-l2)r+(i-l1))w | 同上；r为行数，c为列数，w与B同单位 |

**易错点**

- 行优先乘列数，列优先乘行数，不能凭名称选错乘数。
- 区间两端均包含时，维长有+1；偏移本身不再加1。
- 结果是元素起始地址，不是其最后一个字节的地址。

### 例题：同一非零下界数组的两种布局

**题目：**A[-1..2,2..6]，基址LOC(A[-1,2])=1000，每元素4字节。分别求A[1,5]的行优先、列优先地址。

1. r=2-(-1)+1=4，c=6-2+1=5；行偏移1-(-1)=2，列偏移5-2=3。
2. 行优先：前面2整行共10个元素，再前进3个，偏移13，地址1000+13×4=1052。
3. 列优先：前面3整列共12个元素，再前进2个，偏移14，地址1000+14×4=1056。
4. 数组共20个元素占80字节，起始地址范围1000..1076；两个结果均在合法元素起址内。

**结论：**行优先1052，列优先1056，均为十进制字节地址。

## 广义表：原子、子表、表头与表尾

**复习层级：** foundation；**依据：** likely。

广义表把线性表的元素推广为原子或子表，定义本身具有递归性。判断题先区分当前最外层的元素与嵌套内部元素，再区分某对象是原子还是表。教材允许子表共享与递归表；本节长度和操作演算选用有限、无循环的具体表，不把未点名的其他内容判定为排除。

**核心概念**

- **原子与子表：**原子是当前表示中不可再分的单个值；子表本身仍是一个广义表。一个复杂子表无论内部有多少项，在它的上层只算一个元素。
- **长度：**长度等于最外层元素数，不等于原子总数，也不等于括号对数。空表()长度0，仅含一个空子表的表(())长度1，二者不能互换。
- **表头：**GetHead(L)取非空L的第一个元素，该结果可能是原子，也可能是子表；返回子表时应保留它的结构。空表没有可取的第一个元素。
- **表尾：**GetTail(L)取除第一个元素外的其余元素组成的表，因此结果一定是表；若L仅一项则结果为空表，即使唯一一项本身是空表也如此。
- **共享与递归边界：**名称可引用其他子表形成共享；E=(a,E)是教材的递归表示，展开不会成为有限表，不能盲目用有限展开计数方法处理。

**操作步骤**

1. 从最外层括号内按逗号分项，子表内部逗号不分割上层元素。
2. 取Head时返回第一个元素本身；取Tail时删去第一项并为剩余项保留一层表结构。
3. 连续运算前检查操作对象：必须是非空表，不能对原子或空表继续套用本接口。

**易错点**

- GetTail得到的是表，不能把只剩原子c的表(c)写成c。
- 空表()不是原子；(())不是空表，二者长度不同。
- 不把顶层长度、原子个数、嵌套层数混成一个概念。

### 例题：表尾仍然保留外层括号

**题目：**L=(a,(b,c),())。求长度、Head(L)、Tail(L)、Head(Tail(L))与Tail(Tail(L))。

1. 最外层三项依次为a、(b,c)、()，故长度3。
2. Head(L)=a；删第一项后Tail(L)=((b,c),())。
3. 对该非空表取Head得到子表(b,c)；再取Tail得到仅含空子表的表(())。
4. (())长度1，其Head与Tail均为()；但对()再取Head没有定义。

**结论：**长度3；Head=a；Tail=((b,c),())；Head(Tail)=(b,c)；Tail(Tail)=(())。

**教材来源：**4.5.1 广义表的定义；印刷页122–123（PDF第134–135页）。

### ch04-q06 · 编程

编写首次匹配函数Index_KMP。SString含ch[1..length]；模式非空，pos满足1≤pos≤S.length；next为同一1-based约定的预计算表。失败返回0。

**参考答案**  核心函数（重构类C示例）：
/* SString uses ch[1..length], as in the BF example. */
int Index_KMP(SString S, SString T, int pos, const int next[]) {
    int i = pos, j = 1;
    while (i <= S.length && j <= T.length) {
        if (j == 0 || S.ch[i] == T.ch[j]) { ++i; ++j; }
        else j = next[j];
    }
    return j > T.length ? i - T.length : 0;
}
表示沿用BF示例的SString，ch[0]不用；next容量至少T.length+1。S为空或pos不合法不在本接口前置条件内；T长于剩余主串时正常返回0。

j=0分支必须先判断以利用短路；成功时j=m+1，返回i-m。

1. 初始化i=pos、j=1。
2. j=0或字符相等时同增i、j；否则仅令j=next[j]。
3. 循环结束若j>m返回i-m，否则返回0；总时间含预处理O(n+m)。
