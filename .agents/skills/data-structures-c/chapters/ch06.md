## 图的术语与存储

**复习层级：** foundation；**依据：** emphasis。

图G由顶点集V和边集E组成。有向边为有序对，无向边为无序对。邻接矩阵用n×n数组记录邻接关系或边权，查询直接但空间O(n²)；邻接表按顶点保存其邻边，适合稀疏图。无向图每条边在两个端点的邻接表中各出现一次；有向图只记录弧的起点所发出的边。带权图的路径长度为边权之和，无权图则按边数计。算法前先确定有向性、边权以及不存在的边标记，避免把∞当成可相加的普通值。

**核心概念**

- **邻接矩阵：**A[i][j]表示顶点i到j是否邻接或相应边权。
- **邻接表：**每个顶点保存其相邻顶点/出边链表。
- **度与入出度：**无向图计度；有向图区分入度与出度。

**操作步骤**

1. 确定顶点编号和边的方向。
2. 按题目约定建立矩阵或邻接表。
3. 确认无边标记和对角线取值。

**公式与适用条件**

| 项目 | 公式或结论 | 适用条件 |
|---|---|---|
| 邻接矩阵空间 | O(n²) | n个顶点 |
| 无向图度数和 | 2\|E\| | 按握手定理 |

**易错点**

- 无向边在邻接表中通常记录两次。
- 无边的∞值不能直接参与普通有限数值计算。
- 有向边(u,v)不能自动视为(v,u)。

### 例题：邻接表计数

**题目：**无向图含5条边，用邻接表共记录多少条邻接关系？

1. 每条无向边分别列在两个端点表中。
2. 记录数=2×5。

**结论：**共10条邻接关系。

**教材来源：**6.1 图的定义和基本术语；6.4.1 邻接矩阵；6.4.2 邻接表；印刷页184–193（PDF第196–205页）。

**范围依据：**纪要要求熟悉图的表示与章节概念；本主题统一后续算法的建模口径。

## DFS与BFS遍历

**复习层级：** focus；**依据：** likely。

深度优先搜索沿未访问邻点递归深入，不能继续时回溯；广度优先搜索用队列先访问离起点较近的顶点。每次首次发现顶点就立即标记，再压栈、递归或入队，确保不会反复处理同一顶点。若图不连通，从单一起点搜索无法覆盖全图，需外层循环对尚未访问的顶点再次启动。遍历次序受邻接表顺序影响，题面应给出顺序，否则可存在多个合法答案。邻接表表示下两者复杂度均为O(|V|+|E|)。

**核心概念**

- **DFS：**沿未访问邻点深入，无法继续时回溯。
- **BFS：**用FIFO队列逐层扩展。
- **连通分量：**对仍未访问的顶点再次启动遍历。

**操作步骤**

1. 清空visited标记。
2. 标记起点后开始搜索。
3. DFS递归邻点，BFS则出队后扫描邻点。
4. 非连通图继续检查未访问顶点。

**公式与适用条件**

| 项目 | 公式或结论 | 适用条件 |
|---|---|---|
| 邻接表遍历复杂度 | O(\|V\|+\|E\|) | 顶点和边各被常数次处理 |

**易错点**

- 邻接次序未固定时遍历序列不唯一。
- BFS要在入队时标记，避免重复入队。
- 仅有一个连通分量时才可由一个起点覆盖所有顶点。

### 例题：固定次序BFS

**题目：**无向图A邻接B,C；B邻接A,D；C邻接A,D；D邻接B,C，邻点按字母序，求从A开始的BFS。

1. A出队，B、C依序入队。
2. B出队并发现D。
3. C出队时D已标记。
4. D出队。

**结论：**A、B、C、D。

**教材来源：**6.5 图的遍历；印刷页196–200（PDF第208–212页）。

**范围依据：**纪要将图遍历列为选择题优先；具体序列还依赖起点和邻接访问次序。

### 重构类C示例：邻接表BFS

```c
void BFS(Graph G, Vertex s) {
    InitQueue(&Q);
    visited[s] = true; EnQueue(&Q, s);
    while (!QueueEmpty(Q)) {
        v = DeQueue(&Q); Visit(v);
        for (w = FirstAdj(G, v); w; w = NextAdj(G, v, w))
            if (!visited[w]) {
                visited[w] = true;
                EnQueue(&Q, w);
            }
    }
}
```

- 假设从s所在连通分量开始；全图遍历需外层循环补充其他分量。
- FirstAdj/NextAdj为抽象邻接迭代接口，教材类C示意。

## Prim与Kruskal最小生成树

**复习层级：** focus；**依据：** emphasis。

连通无向带权图的最小生成树覆盖所有顶点、无回路并含|V|−1条边。Prim从指定顶点开始，每轮选连接当前树内外顶点的最小权边；Kruskal将边按权排序，仅接纳连接不同连通分量的边。Prim扩展单个连通树，Kruskal不断合并森林。非连通图不能有覆盖全图的生成树。多条等权边可能产生不同但权值相同的MST；构造题需指定并列规则，或说明任何合法最小树均可。检查解时同时核对连通、无环、边数和总权。

**核心概念**

- **生成树：**连通无向图中覆盖所有顶点且无回路的子图。
- **Prim：**从起点开始增长一棵树。
- **Kruskal：**按权增序选择连接不同分量的边。

**操作步骤**

1. Prim：固定起点，维护树内到树外的最轻边。
2. Kruskal：排序全体边，逐条检查是否成环。
3. 达到|V|−1条边后结束。
4. 复核覆盖全体顶点且总权最小。

**公式与适用条件**

| 项目 | 公式或结论 | 适用条件 |
|---|---|---|
| 生成树边数 | \|V\|−1 | 连通无向图 |
| Kruskal时间 | O(\|E\| log \|E\|) | 主要来自边排序 |

**易错点**

- 把图的边数|E|误作生成树边数。
- Kruskal必须跳过导致环的边。
- Prim每次必须连接当前树外顶点，不能在树内选边。

### 例题：Kruskal四点例题

**题目：**边AB=1、BC=2、CD=3、AC=4、BD=5，求一个MST。

1. 按权排序。
2. 选AB、BC、CD，均不成环。
3. 已经有4−1=3条边。

**结论：**MST为{AB,BC,CD}，总权6。

**教材来源：**6.6.1 最小生成树；印刷页200–205（PDF第212–217页）。

**范围依据：**纪要在“如果出现在综合应用里”的条件下强调最小生成树；并列权值不唯一时需遵循题设或接受等价解。

## Dijkstra与Floyd最短路径

**复习层级：** focus；**依据：** emphasis。

Dijkstra求非负权图单源最短路径：每轮从未确定顶点选当前dist最小者，再松弛其出边；负边可能让已确定距离再次变小，破坏贪心正确性。Floyd求任意两点最短路，依次将顶点k作为可选中间点，检查dist[i][k]+dist[k][j]是否改进dist[i][j]。无边初始化为∞，dist[i][i]=0。若需要输出具体路径，需另存前驱或next矩阵；仅有距离矩阵不够恢复路线。实现时保护无穷值，避免把∞参与加法后产生伪更新。

**核心概念**

- **松弛：**用经由一个顶点的新路径长度改进已有距离。
- **Dijkstra：**非负权图上的单源贪心最短路。
- **Floyd：**逐步增加可作中间点的顶点集合。

**操作步骤**

1. 写明起点或初始化全部点对距离。
2. Dijkstra选择未确定的最小dist并松弛出边。
3. Floyd按k、i、j三层循环更新。
4. 更新路径时同步维护前驱信息。

**公式与适用条件**

| 项目 | 公式或结论 | 适用条件 |
|---|---|---|
| Floyd更新 | dij=min(dij,dik+dkj) | 允许k作为中间顶点 |
| Dijkstra前提 | w(e)≥0 | 标准贪心版本 |

**易错点**

- 负边权不能直接使用标准Dijkstra。
- 距离矩阵无边记∞、对角为0。
- 恢复路径需额外保存中间点/前驱信息。

### 例题：松弛一条边

**题目：**当前dist(A)=0、dist(B)=4、dist(C)=10，且B→C权为3。确定B后更新dist(C)。

1. 经B候选距离为4+3=7。
2. 与当前10比较，取较小值。

**结论：**dist(C)更新为7。

**教材来源：**6.6.2 最短路径；印刷页205–211（PDF第217–223页）。

**范围依据：**纪要条件式地提到最短路径综合题；此处区分单源与多源算法和各自前提。

### ch06-q05 · 编程

写出图的BFS核心过程，并说明何时标记visited。

**参考答案**  用队列；发现邻点时立即标记再入队。

发现即标记可防止多条边将同一点重复加入队列。

1. 标记并入队起点。
2. 出队顶点并扫描邻点。
3. 未访问邻点先标记再入队。

~~~c
BFS(G, s):
  visited[*] = false
  visited[s] = true; enqueue(s)
  while queue not empty:
    v = dequeue()
    for each w in Adj[v]:
      if not visited[w]:
        visited[w] = true
        enqueue(w)
~~~
