## 排序性质与复杂度

**复习层级：** foundation；**依据：** emphasis。

稳定性指关键字相同记录排序后相对次序不变；它与是否原地排序、是否适合链表是不同属性。直接插入和冒泡的常用版本稳定；希尔、快速、堆通常不稳定；归并在相等时先取左段可保持稳定。快速排序平均O(nlog n)、最坏O(n²)；归并和堆最坏O(nlog n)。归并通常需O(n)辅助空间，堆排序可O(1)额外空间。复杂度表要结合具体算法版本和初始序列，不能只因一组有序输入就给一般最坏界。

**核心概念**

- **稳定性：**相等关键字记录排序后相对次序不变。
- **原地：**辅助空间为常数级的算法属性，不等于稳定。
- **最坏界：**对所有允许输入中的最大代价作渐进界估计。

**操作步骤**

1. 逐一比较时间、辅助空间、稳定性。
2. 指出复杂度属于最好、平均还是最坏。
3. 检查算法适用的存储结构与数据条件。

**公式与适用条件**

| 项目 | 公式或结论 | 适用条件 |
|---|---|---|
| 快速排序平均 | O(nlog n) | 划分较均衡 |
| 快速排序最坏 | O(n²) | 每次极不均衡 |
| 归并/堆最坏 | O(nlog n) | 标准实现 |

**易错点**

- 稳定不代表复杂度低。
- 平均复杂度不能代替最坏复杂度。
- 快排不同分区方案的过程和常数操作不同。

## 直接插入与希尔排序

**复习层级：** focus；**依据：** explicit。

直接插入每次把当前记录插入前面已排序前缀，较大记录向右移动；稳定，近乎有序时最好O(n)，一般与最坏O(n²)。希尔排序使用递减增量把记录分组并做组内插入，最后增量1完成全体直接插入。某趟之后，只保证每个增量子序列各自有序，不保证整个序列已全局有序。希尔排序通常不稳定，时间界依赖增量序列。做希尔手算时应明确增量、分组、组内处理顺序；增量没给时，不应给唯一中间序列。

**核心概念**

- **直接插入：**按顺序将待插元素插入已排序前缀。
- **希尔增量：**按增量分组，逐趟递减直至1。

**操作步骤**

1. 将第一个元素视作有序区。
2. 保存当前待插关键字。
3. 较大前驱依次右移。
4. 放入空位；希尔每个增量组独立执行此步骤。

**公式与适用条件**

| 项目 | 公式或结论 | 适用条件 |
|---|---|---|
| 直接插入最好 | O(n) | 输入已升序 |
| 直接插入平均/最坏 | O(n²) | 一般/逆序输入 |

**易错点**

- 把希尔某一增量趟后结果称作全局有序。
- 只在前项严格大于key时移动以保留直接插入稳定性。
- 未写增量序列无法确定希尔每趟结果。

### 例题：直接插入一次

**题目：**把4插入已排序前缀[2,5,7]。

1. 5和7后移。
2. 4放在2之后。

**结论：**[2,4,5,7]，移动两个已有元素。

**教材来源：**8.2.1 直接插入排序；8.2.3 希尔排序；印刷页292–296（PDF第304–308页）。

**范围依据：**纪要明确强调插入排序与希尔排序；题面需要提供初始序列和增量。

### 重构类C示例：0-based 稳定直接插入

```c
for (int i = 1; i < n; ++i) {
    int key = A[i];
    int j = i - 1;
    while (j >= 0 && A[j] > key) {
        A[j + 1] = A[j];
        --j;
    }
    A[j + 1] = key;
}
```

- 数组使用0起始下标，升序；>比较保留相等键相对顺序。
- 教材算法按其类C约定转写，独立示例可按标准C补充类型。

## 冒泡排序与快速排序

**复习层级：** focus；**依据：** explicit。

冒泡排序反复比较相邻记录并交换逆序对；升序的常见从左向右版本会把当前未排序区最大值送到右端，一趟无交换可提前结束。快速排序选择枢轴，按分区约定将区间划成左右子区后递归；平均O(nlog n)，最坏O(n²)，常见版本不稳定。枢轴选取、扫描方向和等值处理都会影响中间结果。这里的 Lomuto 版本用末元素作枢轴，从左向右扫描，严格小于枢轴的元素进入左区。作答必须照题目指定的代码移动下标；缺少明确版本时只描述性质，不把单一划分轨迹当成通用答案。

**核心概念**

- **冒泡：**相邻比较，逆序时交换；每趟缩小未排序区。
- **快速排序：**枢轴划分后递归排序两侧子区。
- **Lomuto分区：**以末元素为枢轴，将较小元素移至左侧，再将枢轴归位。

**操作步骤**

1. 确定升序/降序和当前未排序范围。
2. 按题定版本选择枢轴和扫描方向。
3. 逐次记录比较、交换与指针移动。
4. 分区完成后递归处理两侧。

**公式与适用条件**

| 项目 | 公式或结论 | 适用条件 |
|---|---|---|
| 冒泡最好 | O(n) | 使用无交换提前结束 |
| 快速平均/最坏 | O(nlog n)/O(n²) | 依划分平衡程度 |

**易错点**

- 快排分区版本不同，中间序列可能不同。
- 枢轴归位后不要再纳入左右递归子区。
- 冒泡方向变化会改变每趟固定到位的边。

### 例题：末元素枢轴的 Lomuto 分区

**题目：**对数组 [5,2,7,1,4] 做一次升序 Lomuto 分区，以末元素 4 为枢轴，求分区结果与枢轴下标（从 0 开始）。

1. 取 A[4]=4 为枢轴，令 i=0 指向左区的下一空位。
2. 从左到右扫描 [0,3]，先将 2 交换到下标 0，再将 1 交换到下标 1，此时 i=2。
3. 交换 A[2] 与 A[4]，令枢轴归位。

**结论：**[2,1,4,5,7]，枢轴下标为 2，左右递归闭区间为 [0,1] 和 [3,4]。

**教材来源：**8.3.1 冒泡排序；8.3.2 快速排序；印刷页296–301（PDF第308–313页）。

**范围依据：**纪要明确强调冒泡与快排过程；本库每题标明方向和分区口径。

### 重构类C示例：Lomuto 分区

```c
int partition(int A[], int low, int high) {
    int pivot = A[high];
    int i = low;
    for (int j = low; j < high; ++j) {
        if (A[j] < pivot) {
            swap(&A[i], &A[j]);
            ++i;
        }
    }
    swap(&A[i], &A[high]);
    return i;
}
```

- 此处采用末元素枢轴和单向扫描，教材算法 8.5 使用首元素枢轴与双向扫描。
- 下标从 0 开始，在有效闭区间 [low,high] 上分区。swap 为交换两个整型元素的辅助函数。

## 堆排序与归并排序

**复习层级：** overview；**依据：** suggestion。

堆排序先建堆，再将堆顶与未排序区末端交换并逐步缩小堆区，随后向下筛选恢复堆性质；最坏O(nlog n)、原地但不稳定。归并排序反复把相邻有序段合并，平均和最坏O(nlog n)，通常需O(n)辅助空间；相等时优先取左段可保持稳定。堆的孩子下标要依据0/1起始公式统一；归并的左右输入区间与输出临时区间边界必须一致。两者每趟操作逻辑不同，不要用“取当前最小值”概括替代实际调整/归并。

**核心概念**

- **堆排序：**堆顶反复输出并恢复堆性质。
- **二路归并：**把两个相邻有序段合为一个有序段。
- **稳定归并：**两段键相等时先取左段记录。

**操作步骤**

1. 堆：建初堆，交换堆顶与末端，缩小范围并筛选。
2. 归并：逐对比较两个有序段头部。
3. 处理剩余尾段并写入辅助区。
4. 按趟次扩大合并段长。

**公式与适用条件**

| 项目 | 公式或结论 | 适用条件 |
|---|---|---|
| 堆排序最坏 | O(nlog n) | 标准二叉堆 |
| 归并排序时间 | O(nlog n) | 标准二路实现 |
| 归并辅助空间 | O(n) | 数组版本 |

**易错点**

- 堆排序不稳定；归并稳定性依相等时的选择规则。
- 堆的0起始与1起始孩子公式不同。
- 临时数组下标若不匹配源区间会覆盖或漏项。

### 例题：稳定合并

**题目：**稳定归并[1,4左,8]与[2,4右,7]。

1. 依序取1、2。
2. 两个4相等时先取左段。
3. 继续取右段4、7、8。

**结论：**[1,2,4左,4右,7,8]。

**教材来源：**8.4.3 堆排序；8.5 归并排序；印刷页304–311（PDF第316–323页）。

**范围依据：**纪要要求了解堆与归并，故训练复杂度、稳定性和基本操作；仍保留章节选择练习。

### ch08-q09 · 编程

写出冒泡排序一趟无交换即可提前停止的条件。

常见数组堆排序的性质是哪项？
