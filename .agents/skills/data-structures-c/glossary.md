# 术语表

- **按前驱删除：**带头结点单链表删除某结点q时，先找到其前驱p，再令p->next=q->next，最后释放q。先释放后读取q->next是访问已释放存储。
- **比较指针与候选起点：**i 指向主串当前字符，j 指向模式当前字符；一趟比较中，候选起点始终等于 i-j+1，不能把正在比较的位置 i 当成匹配起点。
- **闭区间更新：**目标较大时low=mid+1；较小时high=mid−1。
- **表示与规则分层：**LIFO和FIFO是逻辑规则；空判定、指针名称及容量限制属于具体表示。指针重合的含义必须先看顺序栈、循环队列或带头结点链队的定义。
- **表示与结点所有权：**每个结点包含数据域与next，S拥有整条未弹出数据链的入口。一次成功压入新增一个结点，一次成功弹出释放一个结点，不能释放仍在链内的后继结点。
- **表头：**GetHead(L)取非空L的第一个元素，该结果可能是原子，也可能是子表；返回子表时应保留它的结构。空表没有可取的第一个元素。
- **表尾：**GetTail(L)取除第一个元素外的其余元素组成的表，因此结果一定是表；若L仅一项则结果为空表，即使唯一一项本身是空表也如此。
- **操作结果：**规定正常完成后结构如何变化及返回什么结果。查询通常不改变对象，插入通常改变对象；接口承诺与某种存储实现应分层讨论。
- **插入移动范围：**原数组下标从n−1递减到i−1，赋值elem[j+1]=elem[j]。写入位置为elem[i−1]；空表只允许位序1，尾插不移动已有元素。
- **成功与失败的代价：**在第i个位序命中需要i次元素比较；长度n的表查找失败需要n次比较。这里数元素相等比较，不把循环条件也算作一次关键字比较。
- **冲突：**两个不同关键字计算到相同地址。
- **抽象数据类型的组成：**由数据对象、数据关系集合和基本操作集合三个部分构成。单列一个值域而没有关系和操作，不是本书要求的完整ADT描述。
- **初始化和空队：**分配一个头结点h，令h->next=NULL，front=rear=h。front==rear是此表示的空条件；与循环队列虽然公式表面相似，但这里比较的是结点指针而非数组下标。
- **初始条件：**规定调用操作前对象和参数应满足的条件，例如访问第i个元素前要求线性表存在且1≤i≤n；不满足前提时不能套用正常结果。
- **代价与适用条件：**成功时不必扫描主串剩余部分；最坏情况下很多候选都比较到模式末尾才失败，时间上界 O(nm)，辅助空间 O(1)，不需要预处理。
- **带权路径长度：**叶权值乘以叶深度后求和。
- **地址单位：**若基地址B以字节计、每元素w字节，则偏移也按字节计算。题目会明确元素大小，不能根据int或指针名称自行假定平台字节数。
- **递推候选：**求next时，i指向模式的当前字符，j表示当前候选前缀位置；字符不等时用 j=next[j] 缩短候选，不能简单只减1。
- **动态空间边界：**链栈没有预设数组容量，但申请内存仍可能失败，因此“链栈永不溢出”不严谨；失败压入应保持原S不变，不产生半接入结点。
- **度与入出度：**无向图计度；有向图区分入度与出度。
- **堆排序：**堆顶反复输出并恢复堆性质。
- **队列的保序性质：**只用普通队尾入、队头出且不丢失元素时，成功出队的元素次序保持成功入队的相对次序；这与队列采用数组还是链表无关。
- **二叉链表：**每个二叉树结点含数据、左孩子和右孩子域。
- **二叉树叶数关系：**在非空二叉树中，若度为0、1、2的结点数分别为n0、n1、n2，则n0=n2+1。
- **二路归并：**把两个相邻有序段合为一个有序段。
- **方案的适用边界：**若使用额外计数器或满空标志，可以设计装满M个元素的另一方案；那时相同指针位置可能需要辅助状态才能判满，不能直接套用本节结论。
- **分块查找：**先查索引确定块，再在块内顺序查找。
- **辅助空间：**通常只统计实现算法额外使用的空间，不把输入本身直接算入辅助空间。固定个数的临时变量为O(1)，随n增长的辅助数组或递归活动记录需要单独计入。
- **复杂度和内存：**保留头、尾指针后单次入队与出队均为O(1)。动态分配仍可能失败；空队虽然没有数据元素，仍占一个头结点的空间，销毁时也要释放它。
- **复杂度与边界：**构造仍为O(m)，辅助空间O(m)，整体匹配仍是O(n+m)量级；具体比较次数可能减少，但不能声称任意输入都严格更快。表和主循环必须沿用同一1-based约定。
- **复杂度与概率：**最坏插入和删除均为O(n)，尾部可为O(1)。等概率选择n+1个插入位置时平均移动n/2个；等概率删除n个元素时平均移动(n−1)/2个。
- **共享与递归边界：**名称可引用其他子表形成共享；E=(a,E)是教材的递归表示，展开不会成为有限表，不能盲目用有限展开计数方法处理。
- **构造：**依输入次序逐个比较至空孩子链接并插入。
- **哈夫曼合并：**每次取候选中两棵最小权值树合并，所得权值加入候选。
- **孩子兄弟表示：**一般树以首孩子、右兄弟两个关系表示。
- **后序：**递归左子树、递归右子树、访问根。
- **回绕与逻辑顺序：**rear数值小于front并不表示空；队列逻辑顺序应从front沿模M逐一枚举到rear之前。删除不会要求整体搬移数组，旧值残留也不算有效元素。
- **回退的依据：**失配后下一候选起点是原起点加1，因此用失配时的旧 i、旧 j 计算 i=i-j+2，再令 j=1；两条赋值的先后顺序有意义。
- **回退位置与长度：**若最长相等真前后缀长度为l，已有l个字符无需重比，下一比较位置为l+1；j=1单独定义为0，代表首字符失配的哨兵状态。
- **结点的度：**该结点所含孩子的个数；叶结点的度为0。
- **局部插入与整体建表：**已知头结点时插入一个新结点只改常数个指针，时间O(1)；连续插入n个输入建表时间O(n)，新增n个数据结点另加一个头结点。
- **可行性、输入与输出：**每一步都应是可实现的基本操作或其有限组合。输入可以为空，例如计算一个已知常量；输出至少一个，可以通过返回值或约定的结果状态呈现。
- **快速排序：**枢轴划分后递归排序两侧子区。
- **连通分量：**对仍未访问的顶点再次启动遍历。
- **链式存储：**结点除了保存数据，还通过指针表达联系，逻辑相邻的结点不要求物理地址相邻；指针域的额外开销也是实现的一部分。
- **列优先：**目标之前有j-l2个完整列，每列r个元素，再加本列i-l1个元素，故元素偏移为(j-l2)r+(i-l1)；这是由教材列序说明直接展开。
- **邻接表：**每个顶点保存其相邻顶点/出边链表。
- **邻接矩阵：**A[i][j]表示顶点i到j是否邻接或相应边权。
- **零值的含义：**修正表除了第1项外也可能为0，表示可直接跳到哨兵；此时匹配循环按j=0分支移动i、j，不应访问模式的0号单元。
- **冒泡：**相邻比较，逆序时交换；每趟缩小未排序区。
- **平衡二叉树：**通过旋转限制左右子树高度差。
- **平均查找长度：**若n≥1且成功命中每个位序的概率均为1/n，成功平均比较次数为(n+1)/2；如果给了失败概率或非均匀概率，应按题设重新加权。
- **评价标准：**首先检查能否正确解决规定范围内的问题，再看可读、健壮以及时间空间效率。处理非法输入的能力属于健壮性，运行更快不能弥补结果错误。
- **前序：**访问根、递归左子树、递归右子树。
- **前缀码：**字符编码对应叶路径，因此字符码之间没有前缀关系。
- **入队与出队：**入队先令p->next=NULL，再rear->next=p、rear=p。出队令p=front->next，保存数据后front->next=p->next；若p==rear，再置rear=front，最后释放p。
- **入队与出队顺序：**入队先判满，再写data[rear]，最后更新rear；出队先判空，再保存data[front]，最后更新front。失败操作不改指针、不写输出，取队头则只读不移动front。
- **三个“头”的区别：**头指针是指针变量，头结点是附加结点，首元结点保存第一个有效元素；它们不是同一概念。初始化后空表L不为NULL，而L->next为NULL。
- **删除移动范围：**保存elem[i−1]后，从下标i递增到n−1，赋值elem[j−1]=elem[j]。删除末元素无须移动；空表没有合法删除位序。
- **生成树：**连通无向图中覆盖所有顶点且无回路的子图。
- **失配转移：**当前 S.ch[i]≠T.ch[j] 时保持 i 不变，令 j=next[j]，将模式中一个可能继续匹配的位置移到当前主串字符处。辅助表只由 T 决定。
- **时间与接口：**next 构造 O(m)，匹配 O(n)，合计 O(n+m)，辅助表 O(m)。此处 T 非空、1≤pos≤n，成功仍返回1-based首位置，失败返回0。
- **时间与语句频度：**语句频度是该语句被重复执行的次数。分析时须说明统计的是循环体还是条件判断，两者次数可能不同；对数循环还要检查变量如何倍增或缩减。
- **使用范围：**仅由模式本身决定，可供多个主串复用；构造耗时O(m)、表空间O(m)。本节只存next[1..m]，不额外计算整串匹配后的next[m+1]。
- **适用边界：**基址B取LOC(A[l1,l2])，元素宽度w与B使用同一地址单位；本节字节编址则w以字节计。普通C二维数组按行存储；公式不能直接套在压缩矩阵或指针行数组上。
- **首次命中：**顺序查找从下标0开始，一旦发现相等就返回j+1。因此有重复关键字时返回最靠前的命中位置，不是所有位置，也不是最后一个位置。
- **树的深度：**所有结点最大层次；按本书约定根结点位于第一层。
- **数据：**包括数值和经过编码的文字、图像、声音等符号，不能把数据的范围缩小为整数或实数。
- **数据对象：**例如某班全部学生记录构成同类元素集合。数据对象说明研究对象的范围，但仅列出集合还没有明确说明其中元素的先后或联系。
- **数据元素与数据项：**在学籍管理中，一名学生的完整记录可作为数据元素，记录内的学号、姓名、专业等字段是数据项；字段值相同并不表示两条记录是同一元素。
- **顺序表与链表比较：**顺序表按位序取值方便但中间插删要移动；链表无需整体搬移却有指针开销，按位序定位仍需遍历。循环、双向等变体会改变表示和操作条件，不能套用本节全部结论。
- **顺序存储：**利用元素在连续存储空间中的相对位置表达逻辑关系，通常由数组实现；此处的“顺序”描述存储安排，不等于元素按关键字有序。
- **四类逻辑结构：**集合只有同属一个集合的关系；线性结构体现一对一关系；树体现一对多关系；图体现多对多关系。这是结构特征的分类，并非要求每个结点都达到相同度数。
- **松弛：**用经由一个顶点的新路径长度改进已有距离。
- **头插不变式：**处理完前k个输入后，头结点后的链恰为这k个输入的逆序，每个结点都可从L到达，最后一个结点next为NULL。
- **唯一恢复条件：**结点互异时，前序/后序与中序配合可以唯一重建。
- **维长与下界：**若A[l1..u1,l2..u2]，则行数r=u1-l1+1、列数c=u2-l2+1；实际下标必须先减各自下界，不能把下标值直接当成行列偏移。
- **尾插不变式：**每轮结束后，r指向最后一个数据结点；尚未插入任何数据时r=L。始终维持r->next=NULL，从L可遍历到已读入的全部元素，次序与输入一致。
- **位序与下标：**a1、a2等表示逻辑位序，elem[0]、elem[1]等表示实现下标。题目若另给任意下界，必须减去相应下界，而不是机械地减1。
- **稳定归并：**两段键相等时先取左段记录。
- **稳定性：**相等关键字记录排序后相对次序不变。
- **希尔增量：**按增量分组，逐趟递减直至1。
- **线索：**用空孩子指针保存指定遍历次序的前驱或后继。
- **线性探测：**冲突后依序检查下一个槽位并循环回表头。
- **行优先：**目标之前有i-l1个完整行，每行c个元素，再加本行j-l2个元素，故元素偏移为(i-l1)c+(j-l2)。教材式(4-13)给出0下界情形。
- **修正规则：**nextval[1]=0；对j≥2，令k=next[j]。若T[j]≠T[k]则保留k，否则取nextval[k]；因为k<j，可由前向后的已算值递推。
- **压入与弹出：**满时压入失败且不写数组；空时弹出失败且不读栈顶。成功压入可写*top++=e，成功弹出可写e=*--top，但须分清后置与前置的时机。
- **已匹配部分：**在 j>0 的比较状态，T[1..j-1] 与当前候选的主串片段相等；回退保留可确认相等的后缀，避免重新比较这部分。
- **有穷性与确定性：**有穷性要求每次合法执行经过有限步骤结束；确定性要求每一步的含义明确。循环体有限并不意味着循环一定终止，必须检查控制变量是否向终止条件推进。
- **原地：**辅助空间为常数级的算法属性，不等于稳定。
- **原子与子表：**原子是当前表示中不可再分的单个值；子表本身仍是一个广义表。一个复杂子表无论内部有多少项，在它的上层只算一个元素。
- **栈的合法输出：**固定输入次序时，可以在任意允许的时刻出栈，但只能取当前栈顶。判断目标输出时，为输出一个尚未入栈的元素，可依次压入到它；若目标已经被别的未弹元素压住，就不能直接取出。
- **长度：**长度等于最外层元素数，不等于原子总数，也不等于括号对数。空表()长度0，仅含一个空子表的表(())长度1，二者不能互换。
- **长度与容量：**长度n是当前有效元素个数，容量是已分配空间能容纳的最大元素数，两者不能混用。访问要求1≤i≤n，插入另允许i=n+1。
- **折半前提：**关键字有序且可随机访问。
- **真前缀和真后缀：**真前缀不含整个被考察串，真后缀也不含整个被考察串；比较对象是失配前已经匹配的片段，不能包含尚未匹配的T[j]。
- **直接插入：**按顺序将待插元素插入已排序前缀。
- **只读栈顶：**取栈顶访问*(top−1)，不改变top；弹出会改变top。输出参数必须指向可写且不与栈内部冲突的对象，失败路径不应产生伪结果。
- **中序：**递归左子树、访问根、递归右子树。
- **中序性质：**互异键BST的中序遍历为严格递增序列。
- **重复字符作用：**重复字符越多，失配后越可能重复遇到同一字符，修正表可跳过这些候选。它不是将所有next项减1，也不是与主串内容一起预处理。
- **主串与模式：**主串 S 是被检索的字符序列，模式 T 是要查找的连续子串。匹配要求字符次序相同且连续，不是从主串任意抽取若干字符。
- **装填因子：**α=n/m。
- **最好、最坏与平均情况：**同一规模的输入可能触发不同路径。平均次数需要输入分布，未给概率时不能擅自平均；日常写复杂度时应交代采用的情况。
- **最坏界：**对所有允许输入中的最大代价作渐进界估计。
- **B树：**结点含多个关键字和多路子树的平衡查找树。
- **BFS：**用FIFO队列逐层扩展。
- **BST序：**左子树<根<右子树。
- **C接口含义：**若在函数内修改调用者的栈顶变量，重构C接口使用LinkStack *S；*S才是实际栈顶。教材的引用参数写法与此等效表达修改意图，但语法不能混用。
- **DFS：**沿未访问邻点深入，无法继续时回溯。
- **Dijkstra：**非负权图上的单源贪心最短路。
- **Floyd：**逐步增加可作中间点的顶点集合。
- **j=0 的哨兵含义：**当第一个模式字符也不能匹配时，next[1]=0。j=0 只是控制状态，不表示读取T.ch[0]；下一轮直接执行 ++i、++j。
- **Kruskal：**按权增序选择连接不同分量的边。
- **Lomuto分区：**以末元素为枢轴，将较小元素移至左侧，再将枢轴归位。
- **Prim：**从起点开始增长一棵树。
