# 复杂度与边界速查

## 公式与复杂度

| 项目 | 公式或结论 | 适用条件 |
|---|---|---|
| 三角循环次数 | Σ(i=1..n)i=n(n+1)/2 | 内层对第i轮恰好执行i次，n≥1。 |
| 倍增循环次数 | k=1; while(k<n) k*=2 的循环体执行 ceil(log2 n) 次 | n为正整数，忽略整数溢出；n=1时为0次。 |
| 按逻辑位序寻址 | LOC(ai)=LOC(a1)+(i−1)×w | 1≤i≤n，元素等长且连续存储。 |
| 一般数组下标寻址 | LOC(A[k])=B+(k−b)×w | B=LOC(A[b])，k在合法范围内；地址和w单位一致。 |
| 成功平均比较次数 | ASL=(1+2+…+n)/n=(n+1)/2 | n≥1，目标必然存在且每个位序等概率。 |
| 失败比较次数 | Cfail=n | 逐个扫描全部n个元素，不使用哨兵。 |
| 插入移动数 | n−i+1 | 在原第i个元素前插入，1≤i≤n+1，空间足够。 |
| 删除移动数 | n−i | 删除操作前长度为n，1≤i≤n。 |
| 等概率平均移动数 | 插入n/2；删除(n−1)/2 | 分别在全部合法插入或删除位序上等概率，删除要求n≥1。 |
| 头插建表的次序 | 输入a1,a2,…,an，结果an,…,a2,a1 | 每次插在同一头结点之后，n可为0。 |
| 建表时间 | 维护尾指针时O(n)；每次遍历找尾时Σ(k=0..n−1)k=O(n²) | 对n个元素逐个尾插，不把输入读取的外部成本另行放大。 |
| 空栈 | S.top==S.base | 有效初始化的教材指针式顺序栈。 |
| 长度与满栈 | len=S.top−S.base；len==S.stacksize时满 | 指针位于同一栈数组内或其尾后一位。 |
| 队空 | Q.front==Q.rear | 预留一个空位，front为队头位置，rear为下一写入位置。 |
| 队满 | (Q.rear+1)%M==Q.front | 数组容量M≥2，最大有效长度M−1。 |
| 队长 | (Q.rear−Q.front+M)%M | 0≤front,rear<M，采用本节空满约定。 |
| 空链栈与操作代价 | S==NULL；单次Push/Pop为O(1) | 无头结点表示；不计内存分配器内部实现的变化成本。 |
| 空链队 | Q.front==Q.rear，且头结点next为NULL | 带头结点且维护尾指针的链队，不使用模运算。 |
| 失配回退 | i ← i-j+2；j ← 1 | 两式顺序执行；i、j 均为失配时的1-based比较指针 |
| 成功返回 | position=i-m | m=T.length，且循环结束时 j>m |
| 最坏代价 | O(nm) 时间，O(1) 额外空间 | n 为主串长，m 为模式长；比较大量重叠候选时 |
| 失配时 | (i,j) → (i,next[j]) | j>0且S.ch[i]≠T.ch[j]；next[1]=0 |
| 总复杂度 | O(n+m) 时间，O(m) 辅助空间 | 包括模式预处理；只计匹配阶段为 O(n) |
| 教材 next 定义 | next[1]=0；next[j]=1+L(T[1..j-1])，2≤j≤m | L 为最长相等真前后缀长度，空边界长度为0 |
| 递推成功 | next[i+1]=j+1 | 当前候选为j=next[i]，且j=0或T[i]=T[j] |
| 教材修正 | nextval[1]=0；若T[j]=T[next[j]]则nextval[j]=nextval[next[j]]，否则nextval[j]=next[j] | 2≤j≤m；先有普通next或使用等价线性递推 |
| 行优先 | LOC(A[i,j])=B+((i-l1)c+(j-l2))w | B=LOC(A[l1,l2])；l1≤i≤u1，l2≤j≤u2；连续等长存储 |
| 列优先 | LOC(A[i,j])=B+((j-l2)r+(i-l1))w | 同上；r为行数，c为列数，w与B同单位 |
| 边数 | n−1 | 非空树 |

## 易混约定

- 教材顺序栈的 top 指向下一空位，top==base 时为空。
- 留一空位的循环队列：front==rear 时为空，(rear+1)%M==front 时为满，有效容量为 M−1。
- 教材 KMP 使用从 1 开始的字符下标，next[1]=0。失配时只回退模式串指针。
- BFS 在顶点入队时标记，访问次序取决于邻接顺序。
- 快排推演先说明枢轴、等值处理和分区方式。
