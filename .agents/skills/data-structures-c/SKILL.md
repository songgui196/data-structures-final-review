# 数据结构（C语言版）· 学习与解题

## 用途

依据《数据结构（C语言版）（第3版）》构建的中文复习参考。先辨明逻辑结构与存储约定，再按步骤演算；涉及考试范围时，区分教材事实与复习纪要中的概率性判断。

## 使用方式

- 解题时打开对应章节，按题目约定选择过程和算法版本。
- 练习时选择对应题型，先展示题面与选项，讲解时再给答案、过程和出处。
- 询问考试范围时，查阅纪要的分值差异与证据等级。

## 解题约定

1. 复述题目给出的下标起点、结点表示、队列/栈边界、排序方向和图的有向性。
2. 对算法逐步记录状态变化；不要只给结论。
3. 先验证前提：折半表有序且可随机访问；Dijkstra边权非负；最小生成树输入连通无向图。
4. 对并列权值、重复关键字、遍历邻接顺序和快排分区版本，遵循题面或说明等价答案。
5. 本书算法描述采用类C；只有明确标为标准C的代码才声称可直接编译。
6. 题库内容为自编练习，不等于教材原题、历年真题或押题。考试纪要和分值冲突见 [考试范围与口径](chapters/scope.md)。
